# 마음 탐정단 — 마음숲 탐험

초등 5~6학년을 위한 브라우저 탐험 게임입니다. 겉모습이나 일부 행동으로 친구를 판단했던 경험을 돌아봅니다.

## 실행

빌드나 설치가 필요 없습니다. `index.html`을 브라우저에서 열거나 정적 웹 호스팅에 저장소의 파일을 함께 올리세요. GitHub Pages에서는 배포할 브랜치의 `/ (root)`를 선택할 수 있습니다.

## 조작과 활동

- 방향키 / WASD: 이동
- E / 스페이스: 가까이 있는 친구와 대화하거나 단서 조사
- 터치: 화면 아래 방향 버튼을 누르고 대화 / 조사 버튼 사용
- 이동이 어려운 경우 ‘이동 없이 활동하기’ 사용
- 친구 만나기 → 첫 느낌 선택 → 지도에서 단서 3개 발견 → 관찰과 추측 구분 → 생각 돌아보기
- 세 친구를 모두 만나면 지도 중앙 수첩에서 자신의 경험을 성찰하고 텍스트 파일로 저장

답변은 서버에 전송하거나 브라우저 저장소에 저장하지 않습니다. 새로고침하면 진행 상황이 초기화됩니다. 완성한 수첩은 내려받아 보관할 수 있습니다. 글꼴 로딩에는 Google Fonts를 사용하며, 실패하면 기본 글꼴로 표시됩니다.

## 파일

- `app.js`: 이야기, 성찰 수첩
- `adventure.js`: 캐릭터 이동, 지도 렌더링, 상호작용
- `style.css`, `adventure.css`: 반응형 화면과 조작 버튼

캐릭터와 지도는 Canvas와 CSS로 직접 그립니다. 참고 사이트의 이미지·코드를 복사하지 않았습니다.
