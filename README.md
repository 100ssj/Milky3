# 마음 탐정단 — 마음숲의 비밀

초등 5~6학년을 위한 브라우저 탐험 게임입니다. 겉모습이나 일부 행동으로 친구를 판단했던 경험을 돌아봅니다.

**플레이:** https://100ssj.github.io/Milky3/

스크롤 없는 전체 창 게임입니다. 도트 마을, 캐릭터를 따라가는 카메라, 미니맵과 게임 안의 대화창으로 구성되어 있습니다. 우측 상단 ⛶ 버튼은 지원하는 브라우저에서 실제 전체화면을 켜거나 끕니다.

탐정은 네 방향으로 몸을 돌리며 팔·다리를 번갈아 움직입니다. 친구들은 각자의 옷과 소품을 가지고 눈을 깜빡입니다. 단서를 조사하면 반짝이는 조각이 탐정에게 이동한 후 이야기가 열립니다. 운영체제의 동작 줄이기 설정에서는 이동·발견·환경 애니메이션을 줄입니다. 지도 속 한글은 도트 그림과 분리해 선명하게 표시합니다.

## 실행

빌드나 설치가 필요 없습니다. `index.html`을 브라우저에서 열거나 정적 웹 호스팅에 저장소의 파일을 함께 올리세요. GitHub Pages에서는 배포할 브랜치의 `/ (root)`를 선택할 수 있습니다.

## 조작과 활동

- 방향키 / WASD: 이동
- E / 스페이스: 가까이 있는 친구와 대화하거나 단서 조사
- Esc 또는 좌측 상단 메뉴: 일시정지, 조작 안내, 이동 없는 활동
- 우측 상단 ♪ 버튼: 효과음 켜기 / 끄기 (기본 꺼짐)
- 터치: 화면 아래 방향 버튼을 누르고 대화 / 조사 버튼 사용
- 이동이 어려운 경우 ‘이동 없이 활동하기’ 사용
- 친구 만나기 → 첫 느낌 선택 → 지도에서 단서 3개 발견 → 관찰과 추측 구분 → 생각 돌아보기
- 단서를 조사하면 발견 애니메이션 뒤에 친구의 이야기가 바로 열립니다. 별도의 퍼즐은 없습니다.
- 같은 단서를 다시 읽어도 진행률은 중복으로 올라가지 않습니다.
- 세 친구를 모두 만나면 지도 중앙 수첩에서 자신의 경험을 성찰하고 텍스트 파일로 저장

Supabase가 연결되면 이름만 입력해 입장합니다. 이름과 진행 상황만 서버에 저장하고, 개인 경험 글은 해당 탭의 sessionStorage에 보관합니다. 같은 탭에서 새로고침한 뒤 같은 이름으로 이어 할 수 있으며, 탭을 닫고 새로 입장하면 별도 기록입니다. 완성한 수첩은 내려받아 보관할 수 있습니다. 글꼴 로딩에는 Google Fonts를 사용하며, 실패하면 기본 글꼴로 표시됩니다.

## 파일

- `app.js`: 이야기, 성찰 수첩
- `adventure.js`: 캐릭터 이동, 지도 렌더링, 상호작용
- `pixel-art.js`: 세밀한 캐릭터·배경 도트 그림과 걷기·발견 효과
- `classroom.js`: 이름 입장, 진행 저장, 새로고침 복원
- `teacher.html`: 교사 접속 키로 확인하는 학생 진행률
- `supabase-setup.sql`: 비공개 테이블과 제한된 저장·조회 함수
- `game.css`: 전체화면 게임 UI, 대화창, 반응형 조작 버튼

`node test.cjs`로 이동·충돌·세 이야기·수첩 해금·일시정지 검사를 실행합니다.

캐릭터와 지도는 Canvas와 CSS로 직접 그립니다. 참고 사이트의 이미지·코드를 복사하지 않았습니다.

## 교사 진행률 연결

1. 본인 계정의 Supabase 프로젝트 SQL Editor에서 `supabase-setup.sql`을 실행합니다.
2. 결과의 `teacher_access_key`는 교사만 보관합니다. 첫 실행에서만 표시되고 재실행해도 바뀌지 않습니다. 저장소에 커밋하지 마세요.
3. `classroom-config.js`에는 Project URL과 **publishable key**만 넣습니다. `service_role`이나 secret key는 사용하지 않습니다.
4. 학생은 게임 주소에서 이름을 입력합니다. 교사는 `teacher.html`에서 교사 접속 키를 입력합니다.

학생 이름과 단서 9개·이야기 3개·수첩 완료 여부만 전송합니다. 학생별 임의 토큰은 해시로 검증하며, 다른 학생 목록과 테이블 직접 접근을 허용하지 않습니다. 교사 접속 키는 메모리에서만 유지됩니다. 이름만으로 동일 학생을 인증하는 구조가 아니므로 새 탭/새 기기는 새 입장 기록이며, 날짜와 입장 시간으로 구별합니다. 이 진행률은 학습 활동 확인용이며 부정행위 방지나 평가 인증 도구가 아닙니다.

키를 분실한 경우 SQL Editor에서 아래를 실행하면 기존 교사 키를 교체할 수 있습니다. 새 키를 안전하게 보관하세요.

```sql
with k as materialized (select replace(gen_random_uuid()::text || gen_random_uuid()::text, '-', '') as token),
changed as (update milky_private.teacher set token_hash=sha256(convert_to(k.token,'UTF8')) from k returning token_hash)
select k.token as teacher_access_key from k join changed on changed.token_hash=sha256(convert_to(k.token,'UTF8'));
```

`node classroom-test.cjs`는 이름 입장·복원·개인 글 비전송을 검사합니다. `@electric-sql/pglite`를 설치한 개발 환경에서 `node db-test.cjs`로 실제 PostgreSQL 권한·잘못된 토큰·진행률 검증을 실행할 수 있습니다. 테스트 데이터는 메모리 DB에만 생성됩니다.
